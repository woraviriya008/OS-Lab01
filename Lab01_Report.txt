3. Analysis:
ในการเทรนโมเดล Machine Learning กับชุดข้อมูลขนาดใหญ่ เช่น ภาพถ่าย 500,000 ภาพ การทราบข้อจำกัดของ OS มีความสำคัญอย่างยิ่งก่อนเริ่มเขียนโค้ด ดังนี้:

1. ข้อจำกัดด้านหน่วยความจำ (OS Memory / RAM Limits):
- ภาพถ่าย 500,000 ภาพ เมื่อถูกแปลงเป็น Tensor หรือ Uncompressed Array จะมีขนาดข้อมูลมหาศาล (หลักสิบถึงร้อยกิกะไบต์) ซึ่งเกินขนาด RAM ของระบบแน่นอน
- หากไม่ทราบขีดจำกัดของ RAM แล้วสั่งโหลดรูปภาพทั้งหมดเข้าหน่วยความจำพร้อมกัน จะเกิดปัญหา Out of Memory (OOM) จนระบบปฏิบัติการ (OS OOM Killer) สั่ง Kill Process ทันที
- การทราบขนาด RAM ช่วยให้เราสามารถออกแบบ Data Pipeline ได้อย่างถูกต้อง เช่น การทยอยโหลดข้อมูลแบบ Lazy Loading / Data Streaming และการกำหนดขนาด Batch Size ให้เหมาะสมกับหน่วยความจำที่เหลืออยู่

2. จำนวน CPU Cores:
- ในกระบวนการเทรนโมเดล CPU มีหน้าที่สำคัญในการอ่านไฟล์จากไดรฟ์, ถอดรหัสภาพ (Decoding) และทำ Data Pre-processing / Data Augmentation (เช่น Resize, Crop, Normalize) ก่อนส่งเข้าสู่การคำนวณ
- การทราบจำนวน CPU Core ช่วยให้เราสามารถกำหนดจำนวนกระบวนการทำงานคู่ขนาน (Multiprocessing) เช่น การตั้งค่าพารามิเตอร์ 'num_workers' ใน DataLoader ได้อย่างพอดีกับคอร์จริงของเครื่อง เพื่อป้องกันไม่ให้เกิดปัญหาคอขวด (CPU Bottleneck) ที่ทำให้การป้อนข้อมูลช้าจน GPU ต้องรอรอบการประมวลผล
